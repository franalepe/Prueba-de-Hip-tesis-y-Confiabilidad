Introducción

En la investigación científica, la Prueba de Hipótesis permite tomar decisiones basadas en evidencia, contrastando afirmaciones sobre parámetros poblacionales mediante datos muestrales. Por su parte, la Confiabilidad evalúa la consistencia de los instrumentos de medición, garantizando que los resultados sean estables y reproducibles.

  • Importancia de la Prueba de Hipótesis: sustenta la toma de decisiones y el control de errores al evaluar diferencias, efectos o relaciones.
  • Relevancia de la Confiabilidad: asegura calidad en instrumentos (tests, cuestionarios), elevando la credibilidad de los hallazgos.

Prueba de Hipótesis

Definición

Es un procedimiento estadístico para decidir si la evidencia muestral es suficiente para rechazar una afirmación (hipótesis nula) sobre un parámetro poblacional.

Tipos de hipótesis

  • Hipótesis nula (H0): declaración de no efecto o igualdad (p. ej., μ = μ0).
  • Hipótesis alternativa (H1 o Ha): plantea diferencia o efecto (p. ej., μ ≠ μ0, μ > μ0, μ < μ0).

Nivel de significancia (α) y regiones de rechazo

El nivel α controla la probabilidad de error tipo I (rechazar H0 siendo verdadera). La región crítica se define por valores extremos del estadístico:

  • Prueba bilateral (H1: ≠): colas en ±zα/2.
  • Prueba unilateral derecha (H1: >): cola en +zα.
  • Prueba unilateral izquierda (H1: <): cola en −zα.

Fórmulas

  • Media (σ conocido, Z): z = ( x̄ − μ0 ) / ( σ / √n )
  • Media (σ desconocido, t): t = ( x̄ − μ0 ) / ( s / √n ), gl = n − 1
  • Proporción (Z): z = ( p̂ − p0 ) / √( p0(1 − p0) / n )

Pasos del procedimiento

  1. Plantear H0 y Ha.
  2. Elegir α y el tipo de prueba (bilateral, derecha, izquierda).
  3. Calcular el estadístico de prueba (z o t).
  4. Obtener p-valor o comparar con el valor crítico.
  5. Decidir: si p ≤ α, rechazar H0; en caso contrario, no rechazar H0.
  6. Interpretar el resultado en el contexto del problema.

Ejemplo numérico breve (Z para media)

Suponga n = 36, x̄ = 102, σ = 12 y μ0 = 100, α = 0.05 (bilateral). Entonces z = (102 − 100)/(12/√36) = 2/(2) = 1.00. El p-valor ≈ 0.317 > 0.05; no hay evidencia para rechazar H0.

Confiabilidad

Definición y propósito

La confiabilidad es el grado en que un instrumento produce resultados consistentes y libres de error aleatorio. Un instrumento confiable aumenta la estabilidad y reproducibilidad de las mediciones.

Métodos de estimación

  • Test–retest: aplicar el mismo test dos veces y correlacionar resultados.
  • Mitades partidas (split–half): correlacionar dos mitades equivalentes del test.
  • Alfa de Cronbach (α): consistencia interna para ítems politómicos.
  • Kuder–Richardson (KR-20 / KR-21): variantes para ítems dicotómicos.

Rangos de interpretación (orientativos)

  • α ≥ 0.90: excelente
  • 0.80 ≤ α < 0.90: bueno
  • 0.70 ≤ α < 0.80: aceptable
  • 0.60 ≤ α < 0.70: cuestionable
  • 0.50 ≤ α < 0.60: pobre
  • α < 0.50: inaceptable

Aplicación práctica

Con datos de respuestas por ítem (por ejemplo, escala Likert 1–5), el α de Cronbach puede estimarse con:

α = (k/(k−1)) · (1 − Σ Var(item) / Var(puntaje total))

Donde k es el número de ítems. En la sección Herramientas Prácticas encontrarás una calculadora para α que acepta una matriz de respuestas.
